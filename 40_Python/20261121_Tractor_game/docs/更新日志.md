# 更新日志

## V1.1（2026-11-24）

> 主题：**把"游戏层面的错误"修干净**。V1.0 之后做了很多"让 AI 更强"的尝试（大多是中性的），
> 但真正有价值的是**人工对局反馈暴露出来的规则/行为 bug**。

### 规则 / 行为修正（会改变对局手感）

- **规则漏洞**：对着拖拉机领出时，手里有对子却可以全出单张（引擎判合法）。
  修了 `is_legal_follow` + 两个动作枚举器（快速枚举器填充时只看点数、完整枚举器的
  组合枚举被 `max_moves` 字典序截断导致找不到合法动作）。
  回归探针：`scripts/probe_legal_gap.py`（两档各 30 局 0 死角）。
- **垫牌取向**：原来排序键只有 `c.rank`，会**优先垫主 2/主 3 这种低点数主牌**，
  也会把分牌当小牌垫掉。改为 `discard_key`：
  **非主牌 > 非分牌 > 不拆对子 > 点数小**。
- **常主 2 不能当小牌**：`card_rank_key` 把 2 排在 3 前面。
  改为按游戏真实牌力（王 > 级牌 > 2 > 主花色 > 副牌），2 抬到 A 之上。
- **甩牌被卡的记录**：现在同时显示"原本想甩什么"和"实际出了什么"。

### AI 能力（小幅提升）

- **AI 会换底了**：反主推迟到庄家埋完之后（`bid_wait_bury`），约 35% 的局会换底。
- **按人工思路埋底**（`bury_smart`）：保存确定最强的牌型（单张A/AAK/AKK）、
  裸对子优先埋、主牌少于 10 张不扣、分数默认不扣。**实测 +0.092**。
- **价值网络加了"门控底牌"特征**（`value_v5_142`）：对埋底的排序相关
  从 +0.066 涨到 **+0.334**、选中最优 19% → 34%。
  （但用它搜索埋底仍然中性；优势网络加底牌也中性。）

### 工具 / 数据

- **对局复盘工具**：
  - `scripts/probe_deal_replay.py`：从存档还原某一墩开始时所有人的手牌
  - `scripts/probe_bad_discard.py`：自动扫"缺门垫牌时垫主牌/垫对子分"
- **存档牌名歧义修复**：`hands_start`/`bottom` 等原来用 `c.short`，
  而小王的 `short` 是 `SJ`、和 **♠J 撞名**。改用 `c.label`（`♠J`/`小王`）。
  测试里的集合比较也一并换掉（否则作弊审计会假阴性）。
- **作弊审计增强**：新增"底牌专项"——不是最后埋底者时，改动底牌内容决策必须不变。
- **AI 强度阶梯**：`scripts/run_ladder.py` 一键跑三档两两对战。

### 修掉的潜伏 bug

- `train_advantage.py` 把 `A`（优势标签）当成特征喂进模型（数据是两列标签时）。
  已加 `two` 参数显式声明。**已部署的 16 个 adv 模型都审计过，没受影响。**
