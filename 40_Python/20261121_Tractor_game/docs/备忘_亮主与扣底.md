# 备忘：亮主与扣底（暂不动手）

> 记录时间：2026-11-23。**只做备忘，没有实施**。
> 写下来的原因是：这两步在"一张牌还没出"的时候就定了，但它们对整局的走向影响很大，
> 而目前 AI 在这两步上用的是最朴素的做法。等真人对抗一段时间、积累出更明确的现象后再回来做。

## 现状（代码里是什么样）

| 环节 | 现在的做法 | 位置 |
|---|---|---|
| 亮主 | 固定公式打分：`花色张数×1 + 大牌×1.5 + 王×2 + 手牌分×0.05`，比对手高 1.5 才反主 | `ai_heuristic.bid` |
| 扣底 | 每张牌算"保留价值"（王 140 / 级牌 130 / 常主 120 / 主 90 + 点数×2 + 分×4 + 对子 18），贪心选 8 张埋掉 | `ai_heuristic.bury` |

两个都已经做过消融：

- `bury_void`（埋底时顺便造缺门）：**−0.050 ±0.102**，中性
- `lead_master`（领出时兑现确定最大的牌）：**−0.070 ±0.105**，中性
- `bid_mode=trump`（按主牌硬度而不是手牌总分亮主）：1500 局 **−0.007 ±0.038**，中性

也就是说：**在现有这套打法下，这两步怎么改都不影响胜率**。这是"暂不动手"的主要理由。

## 为什么仍然觉得有空间

1. **第一局的亮主才决定谁是庄家；之后是轮庄，反主不反庄。**
   （早期这里写成"亮主决定谁是庄家"，不准确。）

   之后各局里亮主/反主的真正价值在**换底**：反主的人拿到底牌、重新埋 8 张。
   这比"换主牌花色"重要得多 —— 因为换底可以**造断门、加强自己的副牌**，
   而且庄家不知道你断了哪门，你却基本能推断出庄家断了哪门。
   更妙的情况：你新叫的主牌花色如果被庄家扣断了门，庄家的主牌会很少，
   还顺手给了你一堆新花色的主牌。

   **而原来的启发式是在 `bid_initial` 就把反主用掉的** —— 那时候庄家还没埋底，
   反主只改了主牌花色，白白把换底的机会浪费了。

   **2026-11-23 实测**：加了 `bid_wait_bury` 选项（反主推迟到 `bid_extra`）。
   行为确实变了 —— 60 局里 0 局换底 → **20 局（33%）出现换底**；
   但强度**完全中性**：600 局 +0.007 ±0.058，配 `bury_void` 1500 局 +0.012 ±0.039。

   > **结论：换底的机会是真的，但"抓住机会"本身不产生强度。**
   > 因为埋底逻辑还是逐张贪心的 —— 它不会利用"看到了底牌"和"能选主牌花色"这两件事。
   > 下一步如果要挖，应该是**换底后的埋底策略**（按"造断门 + 保住甩牌型"整体优化），
   > 而不是"要不要换底"。

2. **扣底决定的是整局的手牌形状**，而不是 8 张牌的单独价值。
   真正重要的是：埋完之后**有几个缺门、留住了几个甩牌型（AAK / AKK）、主牌还剩多长**。
   现在的实现是逐张贪心，看不出这些组合效应。
   （顺带一个观察：启发式**从来不出甩牌、也不出拖拉机**——领出里单张占 96%。
   这可能和扣底不保留甩牌型是同一个根因。）

3. **底牌的分值会被抠底倍数放大**（×1~×64）。埋进去的分，闲家赢最后一墩时会被乘倍数拿走。
   现在完全没有考虑这一点。

## 想不清楚的地方（所以先不动）

- **没有明确的优化目标**。"该不该抢庄"取决于"抢到之后我这手牌能打出多少"，
  而这需要一个"手牌 → 期望得分"的模型——价值网络能给，但它是按"已经开打的局面"训练的，
  没有"庄家/闲家身份"这个维度，直接用会偏。
- **扣底是 33 选 8 的组合**（约 1.4×10⁸），穷举不可能。需要先想清楚"什么样的手牌形状好"，
  才能设计贪心或局部搜索的目标函数。
- **换底**（反主抄底）在自对弈里一次都没发生过（`probe_stale_kitty.py`：80 局平均埋底次数 1.00）。
  也就是说这条路**在 AI 互打的环境里无法验证**，只能靠真人对抗来暴露问题。

## 如果将来要动手，建议的顺序

1. **先量化"庄家身份值多少分"**：用 `eval_luck_skill.py` 的思路，按"我方手牌强度"分桶，
   统计"当庄"和"当闲"的期望差。有了这个才知道"该不该抢"。
2. **再量化"扣底形状"**：把"埋完之后的缺门数 / 留住的甩牌型数 / 主牌长度"当特征，
   和最终得分做相关分析，看哪个真的有用。
3. 有了 1、2 再改 `bid` / `bury`，否则又是在噪声里调参。
