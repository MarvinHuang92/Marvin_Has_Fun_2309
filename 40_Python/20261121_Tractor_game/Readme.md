# 拖拉机（双升 / 80 分）· V1.1

4 人、2 副牌、对面结对的升级游戏。**1 名玩家 + 3 个电脑**，Tkinter 桌面界面，纯标准库。

规则基准见 [docs/游戏规则.md](docs/游戏规则.md)（常主 2、3 起打、抠底减半、甩牌自动声明、反主抄底）。

## 快速开始

双击 **`01_Run.bat`**。它会自动寻找带 tkinter 的 Python，优先使用：

- `D:\Python314\python.exe`
- `D:\Programming\Python_dir_38\python.exe`（本机可用，Python 3.8 + tkinter）
- `D:\Programming\Python_dir_3133\python.exe`
- `%LOCALAPPDATA%\Programs\Python\Python3xx\python.exe`

换机器时编辑 `01_Run.bat` 顶部的候选列表即可。也可以手动：

```bat
D:\Programming\Python_dir_38\python.exe scripts\main.py
```

要求 Python 3.8+ 且勾选了 **tcl/tk and IDLE**。游戏本身**只用标准库**；
只有训练价值/优势网络时才需要 numpy（推理是纯 Python，没有 numpy 也能跑，只是慢一些）。

## 操作

- **亮主/反主**：轮到你时下方出现合法声明按钮；没有合适的牌点"过"。
  - 单张级牌 → 对子 → 小王对（无主）→ 大王对（无主）。
  - 对子亮出后花色锁定，只能反无主；加固自己刚亮的单张不换底。
- **埋底**：你是庄家（或抄底成功者）时，手牌区和底牌区一起显示 33 张，**浅蓝色是底牌**；选 8 张，点"确认埋底"。
- **出牌**：点手牌选择，点"出牌"。多张同花色一起出就是"甩牌"；被卡时系统公开"谁卡住"并按"甩错出小"改出。
- **电脑强度**（工具栏右侧下拉框，**下一局生效**）：
  | 档位 | 一局耗时 | 相对"简单" | 相对上一档 |
  |---|---|---|---|
  | 简单（原始规则） | 12 ms | 基准 | — |
  | **会记牌（推荐）** | 80 ms | **+0.89** | — |
  | **会推理（强 · 快）** | 0.2 s | **+0.85** | **+0.17** |

  （每对 800 局配对、座位轮换。两档相对简单的差距在噪声内，但**会推理直接对战会记牌强 0.17**——
  升级增量不是真 Elo，存在这种非传递性。三档的排序是确定的：简单 < 会记牌 < 会推理。）
- **提示**：用**当前选中的电脑强度**算建议，并自动帮你选中那几张牌。
- **记牌/底牌信息**：左下角显示你曾看过的底牌、最后埋底者、你是否知道最终底牌。
- **手动记缺牌**：每个电脑方框右侧有"单张"和"对子/拖拉机"两组按钮（♠ ♥ ♣ ♦ 主）。
  只是给你做标记，**系统完全不参与判断**；按一下加删除线，再按恢复，每局自动清空。
- **自由笔记**：四个玩家面板下方各有一个文本框（我方是绿色），随便写，程序不读不校验，
  新一局自动清空。适合记"哪张大牌还没出过"。
- **方位**：座位固定为 南（你）/ 东（下家）/ 北（对家）/ 西（上家），面板标题上标着。
- **牌面颜色**：红桃/方块/大王红字，黑桃/梅花/小王黑字；手牌按花色分组、组间留空。

## 规则要点

- 2 副牌 108 张，每人 25 张，底牌 8 张；**2 是常主**；级别从 3 打到 A。
- 主牌顺序：大王 > 小王 > 主级牌 > 副级牌 > 主 2 > 副 2 > A > K > …（副牌跳过级牌和 2）。
- 牌型：单张、对子、拖拉机（2 对以上连续对子）、甩牌。
- 抠底：单张 ×1、对子 ×2、k 连对 ×2^k，封顶 64；按最后一墩**领出**的牌型算。
- 升级：0 大光 +3；5–35 小光 +2；40–75 +1；80 上台 +0；以后每 40 分 +1；先打过 A 获胜。
- 反主抄底：反主/自升无主者拿当前底牌、看牌、重埋 8 张；加固不换底；**庄家身份不变**；
  最终底牌只有最后埋底者知道。

完整规则、边界和变体见 [docs/游戏规则.md](docs/游戏规则.md)。

## 代码结构

**游戏本体**

| 文件 | 作用 |
|---|---|
| `cards.py` | 牌、牌序、常主 2、大小比较 |
| `rules.py` | 牌型/槽位、跟牌、毙牌、赢墩、甩牌卡牌者、抠底倍数 |
| `engine.py` | 发牌、亮主/反主、埋底/抄底、出牌、结算、轮庄、存档 |
| `ui.py` | Tkinter 界面 |
| `storage.py` | `data/` 存档和 `cfg/window.json` |

**AI**

| 文件 | 档位 / 作用 |
|---|---|
| `ai.py` | 「简单」：原始规则型，能出合法牌、会亮主/埋底/跟牌/毙牌 |
| `ai_heuristic.py` | 「会记牌」：记牌 + 缺门推断 + 1 层评估 + 给队友送分 |
| `ai_advantage.py` | 「会推理」：优势网络直接选牌（+ 废牌过滤 / 不白毙 / 牌权） |
| `ai_select.py` | 界面用的门面：三档强度统一成一个接口 |
| `memory.py` | 记牌器（只用公开信息，含缺门与换底推理） |
| `fast_state.py` | 搜索/批量用的轻量状态 |
| `moves.py` | 合法动作枚举（单张/对子/拖拉机/甩牌 + 跟牌填充） |
| `value_net.py` | 价值网络与优势网络的推理（numpy 可选） |
| `ai_search.py` / `ai_pimc.py` / `search.py` / `dds.py` | 搜索类 AI 与双明手求解器（**不在界面里**，评测台可用） |
| `eval_harness.py` | 对局评测台（固定口径 + 逐局配对 + 阵营轮换） |

## 常用命令

```powershell
# 启动 / 冒烟测试
python scripts\main.py
python scripts\main.py --smoke

# 一致性自测（枚举动作与引擎判罚完全一致）
python scripts\tests_search_ready.py
python scripts\tests_pimc.py
python scripts\tests_trusted_moves.py
python scripts\tests_no_cheat.py          # 作弊审计：换掉对手手牌，决策必须不变
python scripts\tests_ui_ai.py             # 界面接线（会开窗口）

# 对战评测（正数 = A 赢；负 = B 强）
cd scripts
python -m tractor.eval_harness --a rule --b heuristic --deals 600
python -m tractor.eval_harness --a heuristic --b adv --deals 300

# 行为探针（量"明显不合理的打法"，不看胜率）
python scripts\probe_waste2.py 60
python scripts\probe_behavior.py 50
python scripts\probe_throw.py 40

# 运气 vs 会不会打（按开局牌力分桶）
python scripts\eval_luck_skill.py heuristic adv 150
python scripts\eval_by_level.py self 120     # 按级数分桶
```

## 已知限制

- 只做 2 副牌、4 人、1 人 + 3 电脑；不做联网/热座。
- 「会推理」一局约 0.2 秒，能感觉到思考停顿；「会记牌」基本无感。
- 界面以功能为主，不是精美皮肤；内容高度约需 1800 px，1080p 屏上会挤（窗口可拉高）。
- 规则实现以 [docs/游戏规则.md](docs/游戏规则.md) 为准；发现偏差先改文档再改代码。
