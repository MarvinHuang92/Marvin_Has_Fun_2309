# 赛道设计备忘

> 仅作设计备忘，不涉及代码改动。  
> 记录时间：2026-11-26

## 核心思路

以后设计随机赛道时，不要只靠“随机生成一条中心线，再检查总长/宽度/弯数”这种粗糙约束。

更合适的做法是：

> **先定义一系列“赛道特征”，再要求每种特征出现多少次、以什么参数出现。**

生成器最终的职责是：

1. 生成一条闭环中心线；
2. 识别/标注每个弯的特征；
3. 检查特征数量、顺序和连接关系是否满足要求；
4. 再检查全局几何约束（长度、宽度、边界不自交、边界曲率、直道长度等）。

这也更接近 README 里“无限生成赛道块（中心线 + 宽度 + 曲率）”的含义：

- 不是只生成任意曲线；
- 而是生成带有可识别特征的赛道块，并让这些块按规则组合成一圈。

## 特征定义

### 1. 发卡弯

按当前新定义：

- 取弯道两侧直道之间的中心线朝向转角；
- 转角绝对值不小于阈值；
- 默认阈值 135°；
- 可调范围 90°–180°；
- 由 `min_hairpin_count` 控制至少出现多少个。

### 2. 高速弯

候选定义：

- 中心线转角在某个范围内（例如 30°–80°）；
- 同时要求中心线最小半径不小于某个值；
- 或要求曲率极值不超过某个上限。

具体参数以后定，但应当明确是“转角范围 + 半径/曲率限制”的组合，而不是只看转角。

### 3. 直角弯

候选定义：

- 中心线转角约 90°（例如 80°–100°）；
- 加曲率极值限制，防止看起来像直角但弯心过尖或过宽。

### 4. 假弯

候选定义：

- 中心线转角小于某个角度（例如 <20°）；
- 可能还需要限制其曲率极值，避免把真正的小弯误判为假弯。

### 5. 之字弯

候选定义：

- 连续两个方向相反的直角弯；
- 连接这两个弯的直道长度不得超过某个上限；
- 也就是说它是一组“左直角弯 → 短直道 → 右直角弯”或反向组合。

### 6. S 弯

候选定义：

- 连续两个方向相反的高速弯；
- 连接它们的直道长度可以设上限；
- 与“之字弯”的区别是弯的转角/半径类型不同。

### 7. N 连发卡弯

候选定义：

- 连续 N 个发卡弯；
- 相邻发卡弯之间的直道长度必须在某个范围内；
- N 本身应作为可调参数。

## 连续特征的识别

连续特征可以通过弯道编号关系识别：

```text
T1 -> T2 -> T3 -> ...
```

如果两个特征在弯道顺序上相邻，就认为它们是连续的；如果中间隔着别的弯，则不是连续特征。

因此生成后需要保留/重建：

- 每个弯的编号；
- 每个弯的起止范围；
- 每个弯的转角；
- 每个弯的方向（左/右）；
- 相邻弯之间的直道长度。

这样才能识别：

- 之字弯：Tn 与 Tn+1 反向、连接直道短；
- S 弯：Tn 与 Tn+1 反向、类型为高速弯；
- N 连发卡弯：连续 N 个弯均为发卡弯，且连接直道长度在范围内。

## 特征数量参数

每种特征都应当有独立的数量约束，例如：

```text
hairpin_count >= 1
high_speed_corner_count >= 2
fake_corner_count <= 4
chicane_count >= 1
s_bend_count >= 1
```

数量参数可以支持：

- 最小值；
- 最大值；
- 精确数量；
- 0 表示关闭该规则；
- `None` 表示完全不限制（具体取决于参数类型）。

## 全局约束仍然保留

特征规则不能替代已有的全局边界：

- 中心线总长范围；
- 宽度范围；
- 弯道数量范围；
- 所有直道的最短长度；
- 最长直道的上下限；
- 边界不自交；
- 边界曲率上限；
- 左右弯数量差；
- 起点位置与朝向；
- 生成器版本、种子可复现性。

## 当前已知的几何冲突

在“发卡弯转角 ≥135° + 最长直道 ≤300 m + 总长 1200–1800 m + 宽度 15–25 m + 8–12 弯”同时生效时，随机生成很难找到合法赛道：

- 135° 发卡弯的相邻直道天然偏长；
- 一圈长度有限时容易超过单条直道 300 m；
- 强行缩短又容易造成边界过窄或自交。

以后可以考虑：

1. 只对发卡弯相邻直道放宽长度上限；
2. 把“直道长度上限”改成“普通直道上限 + 发卡连接直道例外”；
3. 在特征生成阶段就为发卡弯预留足够空间，而不是生成后再检查。

## 一句话总结

> 以后生成赛道应当从“随机曲线 + 全局检查”升级为  
> **“特征语法 + 数量约束 + 连续关系 + 全局几何约束”**。
