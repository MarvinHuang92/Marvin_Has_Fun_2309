# 车辆动力学模型（V3.0）

本文是 `scripts/minirace/vehicle.py` 的说明与推导依据，也是调参时的唯一参照。
所有数字都可以用 `python scripts/probe_physics.py` 复现。
V3.0 的赛道/相机/边界细节见 `docs/赛道与相机.md`。

## 1. 单位、坐标系

- **世界坐标：米、秒、千克、牛顿、弧度**（V2 起物理层完全是 SI）。
- 世界坐标 `x` 向右、`y` 向上；`heading` 从 +x 轴逆时针（rad）。
- 车体坐标：`x` 向前、`y` 向左；`vx` 纵向速度，`vy` 侧向速度（向左为正），
  `r = yaw_rate` 横摆角速度（逆时针为正）。
- **世界尺寸与像素完全解耦**：物理层没有任何 px/缩放参数。V3.0 默认在赛道上
  （几何来自 `cfg/tracks/track.json`，尺寸约 1389 × 932 m，远大于窗口）；关掉
  `track.enabled` 时退回矩形世界 `world.width_m / height_m`（默认 129.6 × 81 m）。
- 屏幕映射只在渲染层：旧版相机用平移/缩放；赛道相机（V3.0）还会按"实际速度方向朝上"
  旋转，并让车固定在屏幕正中（详见 `docs/赛道与相机.md`）。
  车身 sprite 按真实车长（4.5 m）缩放。
- `g = 9.81 m/s²`。

## 3. 单步方程

### 3.1 输入模型（`controls.py`）

键盘是开关量，积分为连续量：方向盘按下 ±2.0/s、松开 4.2/s、中心 ±0.1 虚位归零；
油门按 +1.8/s 到 0.9、松开 -3.78/s；刹车按 +1.8/s 到 0.8、松开 -3.78/s。
这层是"人"的响应，不是车的物理，所以单独一层，AI 也可以绕开（`sim.step_raw()`）。

### 3.2 挡位、发动机转速与扭矩

```
轮速反算转速:  rpm_geared = |vx| / r_wheel × 齿比 × 主减速比 × 60/(2π)
```

- **离合锁止**（`rpm_geared >= idle`）：`rpm = clamp(rpm_geared, idle, redline)`，
  发动机净扭矩 `T = throttle·T_max(rpm) - T_friction(rpm)`；
  `rpm_geared > redline` 时断油（`T = 0`），所以极速由齿比/红线限制。
- **离合打滑**（低速起步）：`rpm = idle + throttle·(launch_rpm - idle)`，
  净扭矩照常传递——于是大油门起步能拉转速、也能把轮胎打滑。
- **怠速**：`throttle≈0` 且 `rpm <= idle+100` 时，怠速控制器把指示扭矩补到等于内摩擦，
  净扭矩为 0，车不会自己溜也不抖。
- **发动机制动**：`throttle=0` 且 `rpm > idle` 时，
  `T = -T_friction(rpm) = -(16 + 0.005·rpm)`，经齿比放大成负的轮上力。

自动挡逻辑：`shift_timer`/`shift_cooldown` 计时；`rpm > shift_up_rpm` 升挡；
`rpm < shift_down_rpm` 或（大油门 + `rpm < kickdown_rpm`）降挡，并检查降挡后转速
不超过红线 96%。换挡期间断油 `shift_time` 秒，两次换挡至少间隔 `shift_interval` 秒。

### 3.3 轮上纵向力与打滑

```
F_drive = T × 齿比 × 主减速比 × 效率 / r_wheel      （倒挡时符号相反）
前/后轴按 drive_split_front 分配
F_brake = -sign(vx) × brake × decel_limit × m       （沿车体纵向）
前/后轴按 front_bias 分配
Fmax_i = μ_i · Fz_i                                 （该轴附着上限）
```

- **驱动力沿轮胎平面**（前轮带转向角）；**制动力沿车体纵向** —— 制动力不跟着方向盘转。
  真实轮胎在抱死滑移时摩擦方向由滑移速度决定，如果强行沿"打满的前轮平面"施加，
  满舵+刹车会凭空产生几 kN 横向力把车甩出去（V2.7 修复的"侧滑/后退感"根因）。
- 驱动/制动分别按轴截断：驱动超过附着标 `wheelspin`，制动超过附着标 `lockup`
  （打滑声音的来源）。之后每轴"驱动 + 制动 + 侧向"在车体坐标下再按摩擦圆**整体截断一次**，
  保证合力不超过 `Fmax_i`。
- **刹车时禁止沿车头反向溜车**：前进挡刹车强制 `vx >= 0`，倒挡刹车强制 `vx <= 0`。
  否则低速侧滑时 `r·vy` 项会把车身纵向速度推成负数，出现"车头还没转过去、车却倒着滑"
  的假象（V2.7 修复）。

### 3.4 纵向载荷转移与载荷敏感性

```
Fz_front = m·g·b/L - m·a_long·h/L
Fz_rear  = m·g·a/L + m·a_long·h/L
μ_i = μ · (1 - load_sensitivity·(Fz_i/Fz_static_i - 1))
```

`a_long` 用轮胎纵向力/质量（不含 `r·vy`），避免甩尾时把向心项误当成纵向加速度。
载荷敏感性让"重载一侧单位载荷抓地力更低"，抑制了 V1 那种"越压越抓"的失控反馈，
是 V2 在极限下能保持稳定的关键之一。

### 3.5 轮胎侧偏力（轮胎坐标系，前进/倒车统一处理）

先算前后轴在**各自轮胎坐标系**下的速度（`u` 沿轮胎平面、`w` 沿轮胎侧向，左正）：

```
u_front = vx·cosδ + (vy + a·r)·sinδ
w_front = -vx·sinδ + (vy + a·r)·cosδ
u_rear  = vx
w_rear  = vy - b·r

α_front = atan2(w_front, max(|u_front|, 0.5))
α_rear  = atan2(w_rear,  max(|u_rear|,  0.5))
Fy_wheel = -μ·Fz·sin(C·atan(B·α))        C = tire_shape, B = Cα /(μC)
```

- 侧偏角分母用 `|u|` 而不是带符号的 `u`：**"胎面被拖向哪边"的符号不随行驶方向翻转**，
  所以倒车时后轴侧向力仍然提供偏航阻尼（正/倒车用同一套公式）。
- 前进小角度下 `-α_front ≈ δ - (vy+a·r)/vx`，与经典自行车模型一致。
- 小角度刚度：`dFy/dα = μ·Fz·C·B = cornering_stiffness·Fz`；
- 峰值侧偏角：`α_peak = tan(π/(2C))/B ≈ 9.4°`，越过峰值后侧向力会衰减
  （这是 V2 和 V1"硬截断"最大的区别，也是高速极限下不甩尾的关键）；
- 车体坐标下的合力/力矩：

```
Fx_body = Fx_f·cosδ - Fy_f·sinδ + Fx_r
Fy_body = Fx_f·sinδ + Fy_f·cosδ + Fy_r
Mz      = a·(Fx_f·sinδ + Fy_f·cosδ) - b·Fy_r
```

- 摩擦圆：`|Fy| <= sqrt(Fmax² - Fx²)`；低速时再乘 `min(1, |vx|/low_speed_fade)`，
  保证静止打方向不会自己转。
- 越过峰值或力被摩擦圆截断都记 `sliding`，`slip_amount` 取纵向/横向超限量的最大值，
  用于 HUD 与打滑声。

> **V2.5 修复的 bug**：V2.4 及更早版本为了处理倒挡，把前后轴侧向力整体乘以
> `sign(vx)`（`travel_sign`）。倒车时这会让后轴偏航阻尼变成"反阻尼"——只要有一点
> 转向/横摆，侧向力就推着车越转越快，表现为倒挡带方向给油时螺旋自旋、松手后反而
> 转得更快。现在改用上面的轮胎坐标系公式，没有 `travel_sign`，倒车与前进共用一套
> 侧偏力模型（`scripts/tests_physics.py` 有倒挡阻尼与"松手后不加速旋转"的回归用例）。

**低速蹭地阻尼（V2.6）**：侧向力在 `|vx| < low_speed_fade` 时会一起淡出，而这个模型里
没有静态摩擦。于是刹车把纵向速度刹住后，残余的 `vy` 与横摆角速度没有任何东西耗散，
会出现"满舵+刹车一直不松、车原地自转停不下来"。为此在 `|vx| < scrub_speed` 时额外施加
与速度成比例的衰减（越接近 0 强度越大）：

```
scrub = 1 - |vx| / scrub_speed
ay   -= clamp(scrub_lateral_damping · scrub · vy, ±μg)          # 侧向速度阻尼
ṙ    -= clamp(scrub_yaw_damping · scrub · r, ±μg·m·max(a,b)/Iz) # 横摆角速度阻尼
```

阻尼本质上是摩擦力，所以它的加速度/力矩也受附着上限 `μg` 约束（否则低速侧滑时
会把速度瞬间拉低、产生不真实的减速度，诊断里还会误报 `SPEED_JUMP`）。

这是对"轮胎低速接触摩擦"的近似，只在 1.2 m/s 以下生效；`scripts/tests_physics.py` 有
"满舵+刹车必须停住且不自转"的回归用例（V2.6）。

### 3.6 积分与边界

```
ax_tyre = Fx_body/m,  ay_tyre = Fy_body/m
ax = ax_tyre + r·vy,  ay = ay_tyre - r·vx
ṙ = Mz/Iz
vx += ax·dt;  vy += ay·dt;  r += ṙ·dt;  heading += r·dt
x += (vx·cosθ - vy·sinθ)·dt;  y += (vx·sinθ + vy·cosθ)·dt
```

空气阻力/滚动阻力沿纵向反向；速度极低且没有油门时直接停车。

**边界**：V3.0 起默认在赛道上，边界不是矩形，而是 `cfg/tracks/track.json` 的中心线 +
宽度 15 m 的赛道带（`minirace/track.py`）：越界时把车推回带内，并去掉世界速度沿墙外
法线的分量、保留切向分量 → **沿墙滑动**，不瞬间停车、无车损。旧版矩形场地
（`track.enabled=false`）仍保留"四边钳住 + 速度清零"的占位实现。
V3.1 的圆形试车场只有最外圈半径 200 m 是墙（Ø360 m 白色虚线仅参考），
撞外墙同样去法向、保切向。赛道几何、相机与碰撞细节见 `docs/赛道与相机.md`。

## 5. 与 V1 的关系

V1 是"单位质量运动学自行车 + 摩擦圆按比例投影"：没有质量、转动惯量、侧偏角、挡位，
横向约束是 `a_lat = v²κ` 直接截断。V2 的变化：

- 用 **2 自由度动力学**（vx、vy、r 三个状态）替代"沿车头的单个速度"；
- 用 **魔术公式轮胎 + 逐轴摩擦圆 + 载荷转移/载荷敏感性** 替代整体加速度投影；
- 用 **发动机扭矩曲线 + 6AT + 离合/怠速/发动机制动** 替代 `power/v` 恒功率近似；
- 物理步长从 120 Hz 提到 **240 Hz**（轮胎侧偏动力学更"硬"）；
- 档位由 1 个 D/R 开关变成 **6AT 自动挡 + R 挡**。

V1 的 `acc_limit / power / resistance` 三个参数被"轮胎/发动机/传动"参数组取代；
V1 里把 `power` 调到 18000 的意图（更强动力）现在对应约 195 kW 峰值功率（1450 kg），
极速仍由齿比/红线限制在 135 km/h 左右，和场地尺度匹配。

## 6. 声音（`audio.py`）

- 默认不加载音频素材：启动时用标准库合成 16-bit 单声道 PCM。
- 发动机：点火频率 `f = rpm/30`（4 缸 4 冲程），含 6 个谐波 + 半阶调制；
  生成 800~7200 rpm 的 **32 档循环音色**（每段取整数周期保证无缝循环）。
  运行时按 `rpm` 在音色表里定位，用两个通道做**交叉淡化**（pygame 不能实时变调）。
- 打滑：一条带拍频/谐波的尖叫循环，音量跟随 `slip_amount`。
- 撞墙：`wall_hit` 上升沿触发一次合成低频“砰”声（0.35 s 冷却）。
- **可选采样包**：V3.17 起支持分组模式——`engine_file` 为怠速循环（0.95×），
  `run_engine_files` 为 6 段运行素材，按目标点火频率 `rpm/30` 生成 64 档音高表
  （运行时双 voice 交叉淡化，只替换非目标 voice）；`shift_file` 在挡位变化时播放；没有 `run_engine_files`
  时保留旧单文件 32 档变调模式。采样包缺失/损坏时回退合成声。
  素材放 `sounds/`（gitignore，不入库），来源与许可见 `docs/音频素材与许可.md`。
- 音量随油门开度变化；`M` 静音；混音器/声卡不可用时自动降级为静音并写日志。
- V3.17.1 起首次音频更新先静音 0.6 s 再淡入 0.4 s，避免开局爆音。

## 7. 未建模 / 已知偏差

- 无横向载荷转移、无侧倾/俯仰自由度、无悬架；
- 无轮胎松弛长度、无车轮转动惯量/滑移率曲线：打滑是"力饱和 + 需求超限"的准静态近似，
  打滑时用近似抬升转速，不是真实的轮速/转速动力学；
- 无差速器：前后轴扭矩固定分配，超出附着上限的部分直接丢弃；
- 无发动机转动惯量、涡轮、变矩器；换挡是"断油 + 齿比切换"；
- 低速侧偏力用 `max(|vx|, 0.5)` 和淡入系数处理，极低速的原地转向是近似；
  低速静态摩擦用 `scrub_*` 蹭地阻尼近似，不是真正的静摩擦/蠕滑（stiction / creep）模型；
- 制动力简化地沿车体纵向施加（不随前轮转向产生横向分量），相当于理想化的 ABS 方向控制；
  没有真正的 ABS / EBD / ESC、没有轮速/滑移率闭环；
- 碰撞/边界：V3.0 赛道模式下用"中心线距离 + 车体矩形投影"近似，撞墙沿墙滑动、无车损；
  旧版矩形世界仍保留；没有逐轮/逐角点接触、没有轮胎墙/缓冲区、没有圈速计时。

## 8. 给下一阶段的接口

- `Vehicle.step()` 返回的 `Telemetry` 包含 AI 需要的观测量：`vx, vy, yaw_rate, beta_deg,
  rpm, gear, a_long, a_lat, slip_amount, wheelspin/sliding/lockup, fz_front/rear,
  slip_angle_front/rear, fx/fy/yaw_torque` 等。
- `Simulation.step(Command)` 走键盘回弹模型，`Simulation.step_raw(throttle, brake, steer)`
  直接接受连续控制量——AI 驾驶员/RL 环境用后者。
- `Simulation` 默认加载 `cfg/tracks/track.json`（V3.0），提供 `sim.track`：中心线点列、宽度、
  起点、最近点查询（AI 可用作横向误差/前视点）、圈长；物理与窗口/显示缩放完全无关。
- 世界 ↔ 屏幕的换算由 `minirace/camera.py` 负责（旧平移相机 + V3.0 旋转跟车相机），
  渲染层不直接算像素长度。
- 调试/抓 bug 用 `minirace/diagnostics.py`（`--diagnose` / `F9`）：逐步记录全部
  `Telemetry` 字段并标记 NaN、单步跳变、换挡抖动、撞界、长时间打滑；它读取的
  `Telemetry` 字段与 AI 观察量一致，排查物理问题不需要进入渲染层。

## 10. AI 驾驶接口（V3.19）

AI 不直接依赖键盘回弹层，接口在 `scripts/minirace/driver.py`：

```python
driver.reset(track)
command = driver.decide(observation)   # DriveCommand(throttle, brake, steer)
```

- `Driver.observe(simulation)` 把 `Telemetry`/车辆状态转成标准观测量；
- AI 通过 `Simulation.step_raw(throttle, brake, steer)` 推进物理；
- 默认 AI 决策 60 Hz，物理 240 Hz；
- 当前规则驾驶员 `RuleDriver` 使用纯追踪 + 曲率限速/提前制动；
- 每个 AI 在 `minirace/ai.py` 中拥有独立 `Simulation`，因此 AI 间无车-车碰撞，
  只与环境边界碰撞；参数和数量在 `cfg/ai.json`，由 `04_TuneAI.bat` 调整。
