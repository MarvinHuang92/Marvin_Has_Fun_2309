## 1. 从底图生成赛道（`scripts/build_track.py`）

构建期工具（不是游戏运行期依赖）：

```bat
:: 运行期只需 Python 标准库 + pygame；重建赛道需要 numpy / scipy / Pillow / opencv
"D:\Programming\Python_dir_38\python.exe" scripts\build_track.py
```

流程：

1. 取黑色像素中**最大的连通域**（赛道带），丢掉 T1..T16 文字；
2. 用赛道带的外轮廓/内轮廓取中点得到中心线（比骨架法更稳，不会有歧义分支）；
3. 平滑中心线并按曲率找长直道：
   - 最长直道 = **T13-T14**（示意图比例记录题目给定 1135 m 约束）；
  整体比例尺按 **真实圈长 5451 m** 标定（本次中心线 4767.2 px → 1.14343 m/px）；
   - 第二长直道 = **T16-T1 主直道**，方向从 T16 端指向 T1 端，即弯道编号 Tn 从小到大的比赛方向；
4. 起点 = 主直道从 **T1 端往回约 1/3** 处（`start_fraction_from_t1=0.33`），车头仍朝 T1；
5. 赛道宽度按 **15 m** 生成左右边界（示意图上的线宽比例不可靠，所以边界由宽度参数决定）；
6. 输出世界坐标（起点为原点、y 向上、单位米）到 `cfg/track.json`。

本次生成的几何：

| 项目 | 数值 |
|---|---|
| 比例尺 | 1.14343 m/px（按圈长 5451 m 标定；示意图 T13-T14 1032 px → 约 1180 m） |
| 中心线点数 | 1363（约 4 m 一个点） |
| 圈长 | **5451 m**（按真实上海赛道长度标定） |
| 赛道宽度 | **15 m** |
| 主直道（T16-T1 检出直段） | 723 m |
| 起点 | 世界原点 `(0, 0)`，从 T1 端往回 1/3，朝向 **69.7°**（沿 T16→T1） |
| 世界包围盒 | 约 1340 × 865 m（远大于 1440×900 窗口） |

`cfg/track.json` 内容：`width_m`、`centerline`、`left_edge`、`right_edge`、`start`
（x/y/heading）、`reference`（直道像素/米、比例尺、圈长、起点比例）、`straights`（若干直道信息）。

> 说明：底图是示意图，各段比例与真实赛道有偏差。整体比例尺按题目给的
> **真实圈长 5451 m** 标定；T13-T14 直道 1135 m 只作为记录/参考（按此比例会变成约 1180 m），
> 赛道宽度按 **15 m** 生成。以后有真实测绘数据时，替换 `cfg/track.json` 即可。

## 2. 双地图、F2/F5 与缩略图（V3.1）

`cfg/sim.json` 的 `maps.list` 提供两张地图：

| id | 编号 | 名称 | 几何 |
|---|---|---|---|
| `circle` | 0 | 圆形试车场 | `cfg/track_circle.json`：Ø400 m 圆形空地，内部 Ø360 m 白色虚线（不是墙），只有半径 200 m 最外圈是墙；起点在圆心正上方、朝左（逆时针） |
| `oval` | 1 | 椭圆赛道 | `cfg/track_oval.json`：两段 1000 m 直道 + 两端直径 800 m 半圆（外边界），宽 25 m，圈长 4434.7 m；只有 T1（右半圆）/ T2（左半圆）两个弯；起点在 T1 前直道从 T1 往回 1/3 处 |
| `shanghai` | 2 | 上海国际赛车场 | `cfg/track.json`（见第 1 节） |

- **F2**：按 `maps.list` 顺序切换地图（0 圆形 → 1 椭圆 → 2 上海）；切换后从新地图起点开始。
  切换时 `Simulation` / `Renderer` 重建；若诊断模式开着会先结束上一段 CSV 再重新开始。
- **记忆上次地图**：当前地图 id 写入 `maps.session_file`（默认 `data/last_map.json`，不入库）；
  下次启动读取它并直接加载该地图的**起点**。文件缺失/损坏 → `maps.default`（默认 shanghai）。
- **F2 选图提示**：缩略图上方显示 `MAP [编号] 名称`、`LENGTH 全长 m`、`BEST 最快圈`；
  没有最快圈时显示 `--:--:--`；圆形试车场不显示 LENGTH/BEST。
- **F5 就近重置**：把车放到离当前位置最近的当前赛道中心线点，朝向沿赛道前进方向，
  速度/横摆清零；**F5 不重置单圈时间**（当前圈继续计时）。圆形试车场特殊设定：F5 回起点。
- **HOME**：始终回当前地图起点；**当前圈号 +1、上一圈用时丢弃**（不更新最快圈），
  重新起步后同样要先离开起跑线 25 m 才武装计时。
- **过线冷却**：正常计圈后 **5 秒内**的重复/反向撞线都不改变圈数和计时起点。
- **右下角缩略图**（不旋转）：按地图世界包围盒等比缩放，画赛道形状/圆形场地、绿色起点、
  红色自车三角（方向随 heading）；尺寸/边距由 `render.minimap` 配置。缩略图始终固定，
  只有相机主画面旋转。

圆形场地的碰撞：`Track._resolve_circle` 只用"离圆心半径 - 车体径向投影 - margin"判定外圈墙，
内部虚线完全可跨越；撞外圈同样去法向、保切向（沿墙滑动）。

### 5 要素弯道窗口（V3.4）

- 在圈速面板下方显示五个要素，小三角始终指向中间：
  - 弯中：`T1 - T2 - T3`（中间弯橙色高亮）；
  - 直道：`- T2 - T3 -`（中间短横线橙色高亮）。
- 数据来源：`build_track.py` 把 T1..T16 标签锚点映射到中心线，并生成 `corners`、
  `elements` 交替序列（弯 / 直道）；`build_oval_map` 直接生成 T1/T2 的元素。
- 划分规则：中心线曲率阈值区分弯/直道；相邻弯之间以曲率绝对值最小点为边界，
  并至少留出 `min_straight` 长度；同向组合弯因此会在最小曲率点处被切成两个弯，
  反向 S 弯按曲率阈值自然分开。
- 运行期 `Track.element_window_at()` 根据最近中心线点找到当前元素并返回前后各 2 个元素。

### 圈速 HUD（V3.3）

- 右上角面板：上海赛道显示 **LAP 当前圈号 / TIME 当前圈时间 / BEST 最快圈**；
  圆形试车场没有圈数，只显示 **TIME**（本图运行时间）。
- 圈速判定（`minirace/laptiming.py`）：在 `track.start` 的切向法平面，从线后穿到线前
  （`along` 由负变正）且横向仍在赛道宽度内记一圈；起跑后先离开 25 m 才武装，避免起步误触发。
- 完成一圈：当前圈号 +1、当前圈时间清零，更新最快圈；随后进入 5 秒过线冷却。
  **F5 不重置单圈计时**；**HOME 才重置**（圈号 +1、上一圈用时丢弃、最快圈保留）。
- 最快圈按地图保存在 `data/last_map.json` 的 `best_laps` 字段（按 `maps.list` 的 id 区分）。

### T6 边界局部平滑（V3.3）

- `build_track.py` 对示意图 T6 附近（像素约 `(1288, 242)`）做局部余弦加权滑动平均
  （半径 180 px、窗口 45、5 遍），只影响 T6 一段，不改变整圈标定（圈长仍 5451 m）；
  之前轮廓中点法在该发夹弯留下的白色边界锯齿/硬折角已被抹平。

### [WRONG WAY] 提示（V3.6）

- 车头与最近中心线方向夹角 **>120°** 持续 **1.5 s** 后，在屏幕中心偏上 1/3 处显示
  橙色 `[WRONG WAY]`；显示 1 s / 消失 1 s 循环，每次进入显示相位响一声 beep。
- 车头回到 120° 内立即隐藏并重置计时；圆形试车场不判定；F2/F5/HOME 会重置。
- 逻辑在 `minirace/warnings.py::WrongWayMonitor`，可独立单测。

### 显示倍率（V3.11）

- `-` / 小键盘 `-` 缩小（远），`=`（即 `+`）/ 小键盘 `+` 放大（近）；
- 共 7 档：`-3 / -2 / -1 / 0 / +1 / +2 / +3`；默认 0；
- 倍率 `2^(level/3)`：**+3 = 2.0×**、**-3 = 0.5×**；
- HUD 的 VIEW 后显示 `(+1)` / `(-2)`，0 档不显示；
- 档位不保存：**F2 切图/本窗口内会保留**，关闭窗口/重新启动后才回到 0 档；
  只改显示 `pixels_per_meter`，
  物理/碰撞/相机角度逻辑不变。

## 3. 相机（`minirace/camera.py::ChaseCamera`）

- **车固定在屏幕正中**（实际偏移 0，满足 ±10% 容差）；相机中心 = 车位置；
- **屏幕上方 = 车的实际世界速度方向**，不是车头朝向：
  `angle = atan2(world_vy, world_vx)`；车头与速度的夹角 β 会让车身相对屏幕有自然的"横滑"角度；
- **倒挡**：相机翻转 180°（速度向量朝下、车头朝上）；前进时仍是速度朝上；
- 角度用**最短路径插值 + 角速度上限**，跨 ±180° 连续，不会整圈翻转；
- **低速冻结**：速度低于 `track.camera.freeze_speed`（默认 1.5 m/s）时保持上一角度，
  避免停车/低速蠕动时镜头抖动；起步后平滑转到速度方向；
- 显示缩放 `track.camera.pixels_per_meter`（默认 6.0）：默认视野约 240 × 150 m。

配置样例（`cfg/sim.json`）：

```json
"track": {
  "enabled": true,
  "file": "cfg/track.json",
  "wall_slide_drag": 0.3,
  "wall_margin": 0.02,
  "camera": {
    "pixels_per_meter": 6.0,
    "angle_rate": 5.0,
    "max_angle_rate": 6.0,
    "freeze_speed": 1.5,
    "center_tolerance": 0.10
  }
}
```

## 4. 赛道碰撞（`minirace/track.py`）

把车近似成"中心点在中心线上、外接投影半径由相对墙面朝向决定"的矩形：

```
support = |cos(相对角)| · half_width + |sin(相对角)| · half_length
allowed = width/2 - support - margin
```

- 车中心到中心线的距离 ≤ `allowed` 时正常行驶；
- 超过时把车**推回边界内**，并把世界速度沿墙外法线的分量去掉（保留切向分量）→
  **沿墙滑动**，不会撞一下立刻停；`wall_slide_drag` 给切向一个很小的衰减（0.3 /s）；
- 设置 `telemetry.wall_hit=True`，诊断模式记为一次 `WALL_HIT`；
- **没有车损**（无耐久/损坏系统），碰撞只影响位置与速度方向。

每物理步只做一次最近段局部搜索（车每步移动 <0.2 m，中心线点间距 4 m），
开销很小；偏离过远时自动退化为全量搜索。

## 6. 已知限制

- 赛道几何来自示意图，不是高精度测绘；圈长按真实 5451 m 标定，T13-T14 直道约为 1180 m；
- 上海赛道宽度固定 15 m；示意图上的弯道半径未按真实比例校正，个别发夹弯视觉上偏紧；
- 圆形场地是简单的"半径墙 + 虚线引导"，没有内场/障碍物；
- 碰撞用矩形投影近似（不是逐轮/逐角点接触），没有车损、没有轮胎墙/缓冲区；
- 圈速只有当前圈/最快圈，没有分段时间、最佳线路、圈速排行；AI 规则驾驶员已接入，强化学习是下一步。
