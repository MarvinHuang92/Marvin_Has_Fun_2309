# 音频素材与许可

## 默认：不需要任何素材

`scripts/minirace/audio.py` 默认用标准库**程序化合成**声音：

- 发动机：32 档循环音色（按 `rpm/30` 点火频率生成谐波），运行时按转速交叉淡化；
- 打滑：带拍频/谐波的尖叫循环，音量跟随 `slip_amount`。

因此仓库本身不含任何第三方音频，克隆下来直接能听到声音。

## 可选：WAV 采样包

如果想要真实录音，在 `cfg/sim.json` 的 `audio.sample_pack` 里指定 WAV：

```json
"sample_pack": {
  "enabled": true,
  "engine_file": "sounds/引擎声音.wav",
  "loop_start_s": null,
  "loop_seconds": 0.5,
  "base_rpm": 2400,
  "min_pitch_factor": 0.45,
  "max_pitch_factor": 2.6
}
```

- 支持未压缩 PCM WAV（8/16/24/32-bit，单/多声道，任意采样率）；程序会自动混成单声道；
- `loop_start_s` 为 `null` 时自动挑选最平稳的片段（对音量波动的惩罚大于对响度的偏好）；
- 循环首尾做 20 ms 交叉淡化，避免爆音；
- 按 `base_rpm` 对应的采样转速生成 800~7200 rpm 的 32 档变调音色；
- 文件缺失/格式不支持时自动回退到程序化合成声，不影响启动；
- 打滑尖叫目前仍使用合成声（采样包里没有合适胎噪）。

## 本机素材来源与许可（重要）

`40_Python/20261125_Mini_Race_2/sounds/引擎声音.wav`：

- 来源：用户在 [爱给网（aigei.com）搜索"发动机"音效](https://www.aigei.com/s?q=%E5%8F%91%E5%8A%A8%E6%9C%BA&type=sound) 找到的素材；
- 格式：PCM WAV，16-bit 双声道 22050 Hz，27.1 s（多个转速片段拼接，末尾约 2 s 静音）；
- **许可状态未核实**：爱给网素材的授权由每个素材详情页单独标注（常见为"仅供学习交流、
  不可商用"，部分为 CC0/免费商用）。搜索页不能作为授权依据；需要以具体素材详情页的
  授权说明为准。若无法确认，请按"版权不明"处理。
- **使用范围：仅本机个人练习**。`sounds/` 已在 `.gitignore` 中，不随代码提交/分发；
  不要把该文件放进公开仓库、分享的构建包或公开视频。若以后要分享项目，请删除/替换成
  CC0、自己录制或已购买授权的素材（或直接把 `sample_pack.enabled` 设为 `false`）。
- 代码只读取该文件，不修改它；也不会修改 `D:\Program Files (x86)\NFS5Porsche_en` 等
  任何游戏安装目录。

## 换成自己的素材

1. 把 WAV 放进 `sounds/`（目录已被 gitignore）；
2. 改 `audio.sample_pack.engine_file` 指向它；
3. 如果自动挑的循环段不好听，设置 `loop_start_s`（秒）手动指定；
4. 如果音高不对，调 `base_rpm`（采样对应的发动机转速；怠速/红线音色会随之缩放）；
5. 跑 `python scripts/tests_audio.py` 确认加载/回退逻辑正常；
6. 启动游戏看 `logs/run.log` 里是否有 `采样包发动机声：...` 的记录。

## 代码层面的保护

- 采样包是**可选**的：配置缺失/文件不存在/格式错误 → 回退合成声并写日志；
- 素材目录 `sounds/` 被 gitignore，仓库克隆/提交不会带上任何未授权音频；
- `scripts/tests_audio.py` 用临时生成的合成 WAV 测试采样包，不依赖真实素材。
