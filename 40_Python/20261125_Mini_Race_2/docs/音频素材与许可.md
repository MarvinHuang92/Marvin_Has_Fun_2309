# 音频素材与许可

## 默认：不需要任何素材

没有 `sounds/` 素材时，`scripts/minirace/audio.py` 会用标准库**程序化合成**声音：

- 发动机：32 档循环音色（按 `rpm/30` 点火频率生成谐波），运行时按转速交叉淡化；
- 打滑：带拍频/谐波的尖叫循环，音量跟随 `slip_amount`；
- 撞墙：低频“砰”声合成（按碰撞前速度控制音量，0.35 s 冷却）；
- 换挡：没有采样文件时不额外播放。

因此仓库本身不含第三方音频，克隆下来也能直接听到合成声。

## 当前本机采样包

本机 `sounds/Car_Engine_Gear_Shift_Hum_Loops/` 使用
[Soundza: Car Engine, Gear Shift & Hum Loops](https://soundza.com/packs/car-engine-gear-shift-and-hum-loops)
（页面标注包含 Ziph / OpenGameArt 的 **CC0** 素材）。之前来源/许可不明的
`sounds/引擎声音.wav` 已删除，不再参与加载。

映射关系（`cfg/sim.json -> audio.sample_pack`）：

| 用途 | 文件 |
|---|---|
| 怠速循环 | `soundza-car-engine-loop-1.wav` |
| 运行声音 | `soundza-car-engine-loop-8.wav` ~ `loop-13.wav`（按 `rpm/30` 目标频率生成 64 档音高表，再交叉淡化） |
| 换挡 | `soundza-gear-shift-1.wav`（检测到挡位变化时播放一次） |
| 打滑 | 仍使用程序合成的尖叫音（采样包没有合适胎噪） |
| 撞墙 | 程序合成的低频“砰”声（不依赖素材） |

配置示例：

```json
"audio": {
  "sample_pack": {
    "enabled": true,
    "engine_file": "sounds/Car_Engine_Gear_Shift_Hum_Loops/soundza-car-engine-loop-1.wav",
    "run_engine_files": [
      "sounds/Car_Engine_Gear_Shift_Hum_Loops/soundza-car-engine-loop-8.wav",
      "sounds/Car_Engine_Gear_Shift_Hum_Loops/soundza-car-engine-loop-9.wav",
      "sounds/Car_Engine_Gear_Shift_Hum_Loops/soundza-car-engine-loop-10.wav",
      "sounds/Car_Engine_Gear_Shift_Hum_Loops/soundza-car-engine-loop-11.wav",
      "sounds/Car_Engine_Gear_Shift_Hum_Loops/soundza-car-engine-loop-12.wav",
      "sounds/Car_Engine_Gear_Shift_Hum_Loops/soundza-car-engine-loop-13.wav"
    ],
    "shift_file": "sounds/Car_Engine_Gear_Shift_Hum_Loops/soundza-gear-shift-1.wav",
    "run_engine_frequencies": [73.5, 82.5, 92.5, 104.0, 116.5, 131.0],
    "run_loop_seconds": 1.5,
    "pitch_steps": 64,
    "idle_pitch_factor": 0.95,
    "target_peak": 0.55,
    "crash_volume": 0.85
  }
}
```

- 游戏开局先静音 `startup_delay_s`（默认 0.6 s），再用 `fade_in_s`（默认 0.4 s）淡入；
- 支持未压缩 PCM WAV（8/16/24/32-bit，单/多声道，任意采样率）；
- 分组模式按目标点火频率 `rpm/30` 生成 64 档音高表：每档选 8~13 段中主频最接近的素材，
  重采样到目标频率；运行时按 RPM 在相邻档交叉淡化，且只替换不在目标集合里的 voice，
  避免两路同时重启造成断续；
- `run_engine_frequencies` 为 8~13 段的实测主频；`idle_pitch_factor` 为怠速变调系数；
- `run_engine_files` 留空时，回退到旧的单文件模式：自动挑平稳段 + 32 档变调；
- 文件缺失/格式不支持时自动回退到程序化合成声，不影响启动；
- 采样包是**可选**的，`sounds/` 已在 `.gitignore` 中，不随代码提交/分发。

## 换成其他素材

1. 把 WAV 放进 `sounds/`（目录已被 gitignore）；
2. 修改 `audio.sample_pack.engine_file` / `run_engine_files` / `shift_file`；
3. 单文件模式可设置 `loop_start_s` 指定循环起点；
4. 跑 `python scripts/tests_audio.py` 确认加载/回退/触发逻辑正常；
5. 启动游戏，在 `logs/run.log` 里确认音频初始化和采样包加载日志；
6. 只使用自己录制、CC0、已购买或明确授权的素材；公开分享前再次核对素材页许可。

## 代码层面的保护

- 采样包缺失/损坏 → 自动回退合成声并写日志；
- 素材目录 `sounds/` 被 gitignore，提交不会带上未授权音频；
- `scripts/tests_audio.py` 用临时生成的合成 WAV 测试单文件/分组/换挡/撞墙，
  不依赖真实素材。
