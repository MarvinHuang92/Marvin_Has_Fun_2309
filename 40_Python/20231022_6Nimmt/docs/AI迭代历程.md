> 这份是**过程总结**，不是操作手册。逐轮的原始数据在 [优化记录.md](优化记录.md)（1638 行）。

## 0. 一句话总结

**从 66.7% 走到 95.5%（vs 随机对手），14 个点里有 12 个点来自「第九~十一轮」这三轮：
先做一个不学习的搜索型玩家（92.7%），再把它蒸馏进网络（85%），最后让网络只负责剪枝、
搜索负责决策（94~95.5%）。**

前面八轮各种"调网络"加起来只涨了约 3 个点。

## 3. 有用的事（按贡献排序）

| 排名 | 方法 | 收益 | 为什么有用 |
|---|---|---|---|
| 1 | **先做一个搜索型玩家，再拿它当老师** | 74.5% → 92.7% 的老师，学生 85% | **老师的天花板就是学生的天花板。换老师比调优化器有用一个数量级。** |
| 2 | **让"规划"参与决策** | +17 ~ +28 个点 | 这个游戏的难点不是"评估这一手"，而是"后面会不会被迫吃牌"。网络学不会的东西，rollout 直接算。 |
| 3 | **网络剪枝 + 少量候选的搜索** | 85% → 95% | 网络的正确用法是**先验/剪枝**（省算力），不是直接给答案。同算力下"少而精"胜过"全算一遍"。 |
| 4 | **把好信息当特征** | +6 个点 | 老师算出来的逐动作估值，比任何自造特征都强。**信息 > 结构。** |
| 5 | **软标签（学"值"）而不是动作标签** | +2 个点，且随标签质量放大 | 搜索的决策自一致率只有 45~51%，学动作等于背噪声；学代价曲线才学得到知识。 |
| 6 | **先把评测钉死** | 省下无数次误判 | 第四轮之前有一半的"提升"是噪声。 |

## 4. 没用、甚至有害的（都是实测）

| 方法 | 结果 | 原因 |
|---|---|---|
| 自造特征：已出牌 one-hot / 行段 / 手牌牛头 | 0 ~ −2 | 标签（老师的启发式）**根本不看这些信息**，特征再全也没人用 |
| 换标签：reward-to-go | **−10.8** | 单一动作的样本反事实不可识别，方差爆炸 |
| 换标签：优势 `A = G − V(s)` | −6（相对最优） | 基线能降方差，但抵不过"标签变差" |
| 残差结构 `score = α·t + net` | 0 | RL 的优势信号不足以指出"老师哪里错了" |
| 成对比较（pairwise hinge） | −0.65 | 只是换了损失形状，拟合同一个老师 |
| 状态归一化 | 0 | 信息量比量纲重要 |
| KL 约束的保守 RL | 0 | 优势信号太弱 |
| 容量 120 → 400 | +0.3 | 瓶颈不在容量（30 → 120 那步有用，+3） |
| 数据 12500 → 25000 局 | +0.3 | 已饱和 |
| rollout 预算 M=12 → 24 → 48 | 24 饱和 | 决策差距小于噪声，加钱没用 |
| 吃行也搜索 | +0.4 | "必须吃行"里挑最少牛头已接近最优 |
| **网络先验混进 rollout 代价** | **−1.5 ~ −3.2** | 两个信号同源、质量不同，做"平均"等于用差的污染好的 |
| rollout 延续策略换成随机 | 只 −1.4 | 说明延续策略也是弱杠杆（原本以为是主要瓶颈） |
| **偷看对手手牌**（诊断） | **0** | 对手是随机的，知道手牌只减方差、不改期望——剩下的差距**不是信息问题** |

## 5. 五条可迁移的方法论

1. **先量上限，再谈优化。** 第九轮花半天写了个不学习的搜索玩家，才知道"76% 不是天花板"。
   如果一直在 74~76% 里调网络，再调十轮也不会有突破。
2. **先找瓶颈在哪一类变量上**：信息（特征/老师）> 算法（搜索/规划）> 结构（容量/损失）。
   经验值：换老师 +9.35，加特征 +6，换损失函数 ±0.5。
3. **弱信号不要"平均"，要选对的。** 网络分数和 rollout 代价混合直接掉 1.5~3.2 个点。
   两个高度相关的信号求平均 ≈ 用差的那个污染好的那个。
4. **标签有噪声时，别学标签本身。** 学"值"（软标签）而不是"动作"。
5. **一个假设一个实验地排掉，别堆直觉。** 最后几轮里三个"直觉上应该有用"的东西
   （吃行搜索、偷看手牌、加强延续策略）全部被证伪——这才是"知道到顶了"的依据。

## 6. 和拖拉机项目的对照

两个项目结构不同（6 Nimmt 是多人同时行动、拖拉机是 2v2 不完全信息），
但踩的坑和有效的东西高度重合：

| 现象 | 6 Nimmt | 拖拉机 |
|---|---|---|
| **换老师 / 换决策方式 ≫ 调参** | 换老师 +9.35 个点 | 换决策方式 +0.60 增量；调参全部为 0 |
| **钉死评测是前提** | 第四轮之前一半提升是噪声 | 不配对不轮换会引入 0.03~0.2 偏置 |
| **数据 / 容量会饱和** | 数据翻倍 +0.3、容量 4 倍 +0.3 | 数据翻 5 倍只降 6% MSE，强度不动 |
| **加自造特征没用** | 因为老师不看这些信息 | 因为瓶颈在"评估"，不在"信息" |
| **代理指标 ≠ 实力** | reward-to-go 标签"更高级"却 −10.8 | 相关性掉一半、MSE 砍一半，强度可以不变 |
| **搜索是真正的杠杆** | 搜索型玩家直接 92.7% | 但拖拉机里搜索**打不过**启发式（没有可用真值） |
| **"混合两个信号"有害** | 网络 + rollout 混合 −1.5~−3.2 | 没有直接对应实验，但"加信息全是 0"同理 |

**最大的差异在"搜索好不好用"**：

- 6 Nimmt 的 rollout **能算出真实的后续代价**，所以搜索是老师，蒸馏后学生也很强；
- 拖拉机的搜索叶子只能靠估价（没有足够深的真值），所以搜索一直在自我重复，
  最后是**直接从真实对局结果学"这一手好不好"**（优势网络）才跳出去的。

> 这条差异值得记住：**"能不能拿到可信的后续评估"决定了搜索值不值钱。**
> 能拿到 → 搜索当老师，蒸馏；拿不到 → 别指望搜索，直接从结果学。

## 7. 如果还想往上打

1. **换评测口径**：现在是"打完全随机的对手"，95% 已接近这个设定的天花板。
   有意义的对手是"人类"或"另一个 hybrid"（自对弈）。
2. **换算法族**：rollout 是"均匀采样 + 平均"，真正的 MCTS 会把预算集中到有希望的分支并带网络先验
   （AlphaZero 的形态，工程量比这十四轮加起来还大）。
3. **学习"不确定性"本身**：现在网络只输出"哪个动作好"，不输出"有多确定"。
   能输出代价分布，才能做真正的"按置信度分配预算"。
