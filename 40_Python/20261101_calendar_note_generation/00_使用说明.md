# 月度记事表 · 使用说明

双击 `01_Run.bat`，输入年份，就能得到一份可以打印出来、手写安排全年的日历表（公历 + 农历）。

## 一、怎么用

1. 双击 **01_Run.bat**
2. 按提示输入年份（1970 - 2100），回车
3. 生成完会问“现在打开这个文件吗”，直接回车（= 是）就用 Excel 打开
4. 文件位置：`output\月度记事表_年份.xlsx`

小提示：

- 在“请输入年份”这一步直接回车 = 退出程序。
- 同一年份的文件已经存在时，会先问要不要覆盖（默认 **不覆盖**）。
- 不用管 Python 装在哪，`01_Run.bat` 会自己找；万一找不到，把 `python.exe` 的完整路径加到 bat 里的候选列表即可。
- 第一次运行如果缺库（`openpyxl`、`lunar-python`），会自动安装（先走默认源，失败再走清华镜像），需要联网。

## 二、生成的表格长什么样

### 第一页：12 个月的日历

- 每个月固定 **7 行**：1 行标题（`2026 年 3 月    事件记录`）+ 1 行星期（Mon ~ Sun）+ 5 行日期。
- 12 个月共 84 行，行数、列数永远不变；行高、列宽、字体、边框都用 `template` 里的模板表格。
- 第一列（A 列）是周次 `Week 01` ~ `Week 53`：
  - 1 月 1 日所在的那一周固定算第 1 周；
  - 每周从周一开始，跨月接着往下数，所以相邻两个月首尾可能显示同一个周次（有意为之，方便对照）。
- **每个日期格写在同一行**：`日号 农历`，公历和农历之间一个空格。当天有节日或节气时，农历位置换成节日 / 节气：

  | 优先级 | 显示内容 | 例子（2026 年 10 月） |
  | --- | --- | --- |
  | 1 | 节日（公历 + 农历） | `18 重阳节`、`1 国庆节` |
  | 2 | 二十四节气 | `23 霜降`、`8 寒露` |
  | 3 | 农历日期 | `17 九月初八` |

  - 节日和节气撞在同一天时**两个都显示，节日在前**，例如 1992 年 2 月 `4 春节 立春`、1993 年 10 月 `23 重阳节 霜降`。
  - 闰月显示成 `闰六月初一` 这样。
- 日期不满 5 行的月份：剩下的行留空。
- 每个月都从第一行开始写：1 号是星期几就落在第几列（比如 2027 年 3 月 1 日是周一，整月就从第一行周一开始排，月末不会绕回）。
- 日期超过 5 行的月份：多出来的日期会“绕回”该月第一行的空格，格子末尾用 `(w周次)` 标出它真正的周次，例如 2026 年 11 月第一行的 `30 十月廿二 (w49)`。
- 极少数年份（1984、2012、2040、2068、2096 —— 闰年且 1 月 1 日是周日）一年会横跨 54 个自然周，这时 12 月会出现 `(w54)` 标记，属正常现象。

### 第二页：说明页

照抄 `template` 里模板的第二页，内容没有改动：记录行高、列宽的像素尺寸，以及自定义页边距的数值。

## 三、打印

- 页面已经设成 **A4 横向 + 模板第二页记录的自定义页边距**（页眉 0.8、页脚 0.3、上 2.4、下 0.9、左右 0.6 厘米），打印缩放 100%。
- 实测结果：**一个月正好一页**，共 12 页日历 + 1 页说明。直接 Ctrl+P 打印即可，不用再调页面设置。

## 四、目录说明

| 路径 | 作用 |
| --- | --- |
| `01_Run.bat` | 唯一入口，双击运行 |
| `scripts\generate_calendar.py` | 主程序：询问年份、读模板、填内容、存文件 |
| `scripts\calendar_layout.py` | 排版计算：周次、每月 5 行的日期网格 |
| `scripts\lunar_labels.py` | 农历日期、二十四节气、国内节日 |
| `scripts\check_dependencies.py` | 检查并自动安装 `dependencies.txt` 里的库 |
| `dependencies.txt` | 依赖清单（openpyxl、lunar-python） |
| `template\` | 输出表格的模板，程序只改第一页的内容，其余原样保留 |
| `output\` | 生成结果 |
| `tool_dev_req\` | 需求原文、开发笔记，用户不用看 |

## 五、常见问题

**双击后窗口一闪就没了？**
说明生成成功并正常退出。如果生成失败，窗口会停住并显示错误信息。

**提示找不到 Python？**
装一个 64 位 Python 3，或者把 `python.exe` 的路径加到 `01_Run.bat` 的候选列表里。

**提示依赖安装失败？**
多半是网络问题，程序会自动换清华镜像重试。仍然失败时可以手动执行：

```bat
"D:\Programming\Python_dir_38\python.exe" -m pip install -r dependencies.txt
```

**想改节日清单，或者想调整样式？**
节日清单在 `scripts\lunar_labels.py` 顶部两张表里加/删即可；表格样式改 `template\` 里的模板文件。
